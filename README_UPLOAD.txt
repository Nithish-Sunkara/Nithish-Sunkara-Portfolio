# Nithish Sunkara — Portfolio (Apple-inspired visual refresh)

The pages retain the previous portfolio text, dashboard screenshots, links, and Google Analytics ID. Only the visual presentation was changed.

## Update GitHub Pages
1. Extract this ZIP.
2. In your existing `Nithish-Sunkara-Portfolio` repository, replace `styles.css` and `contact.html`. The other three HTML files are included for completeness and can also be replaced.
3. Keep the `assets` directory and `script.js` alongside the four HTML files at the repository root.
4. Commit and refresh your website. No custom domain is needed.

The redesign uses an Apple-inspired minimalist aesthetic but is not affiliated with Apple.
